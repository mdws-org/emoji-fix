# Emoji Fix privacy policy

Effective 2026-10-12.

Emoji Fix does not collect, transmit or sell any data.

- It does not make network requests. Its font is a file inside the extension package.
- Its scripts run on the pages you visit to find text that contains emoji. They read the page's text and font styles in your browser and change the `font-family` style of the elements that contain emoji. Nothing they read leaves the page or is saved.
- The only thing it stores is the list of site names you turned the extension off for. The list is kept in the browser's extension storage, which your browser syncs between your own devices if you have sync turned on. It is not sent to the developer or anyone else.
- It does not use analytics, cookies or remote code.

Questions: open an issue at https://github.com/mdws-org/emoji-fix/issues.

Changes to this policy are published in this file, and its history is in this repository.
